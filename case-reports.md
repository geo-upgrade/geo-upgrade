# Кейс: бот Отчёты — автозамеры AI-видимости дважды в неделю | GEO-Апгрейд

> URL: https://geo-upgrade.ru/case-reports.html

**Назначение:** Страница кейса: как учебный замер отслеживателя вырос в автоматическую систему — бот «Отчёты» по cron вторник и суббота 12:00 (НСК) прогоняет 20 фиксированных вопросов по двум упоминателям, считает диф к baseline и присылает сводки с DOCX-отчётами в Telegram.

**Описание (meta):** Автоматический замер AI-видимости: бот Отчёты по cron дважды в неделю шлёт сводки и DOCX-отчёты в Telegram. Кейс AI-видимости бренда Дарьи Жарких.

Case type: Lab Protocol

- Экспонат: EXH-10 · бот «Отчёты» (автозамеры упоминателей)
- Запуск: 19 октября 2026 · первый плановый прогон — 20 октября в 12:00 по Новосибирску
- Работа: автозамер AI-видимости по 20 вопросам · два упоминателя: компания и основатель
- Расписание: cron вторник и суббота, 12:00 (UTC+7, Новосибирск) · сводки + DOCX в Telegram
- Модель: YandexGPT (Yandex AI Studio, API с веб-поиском) · 20 фиксированных вопросов
- Baseline: обновляется автоматически после каждого прогона · диф считается к предыдущему замеру
- Инфраструктура: GitHub Actions (workflow 13 шагов), без серверов и бюджета
- Ограничения: шоты размечаются автоматически — спорные сверяются вручную; вариативность канала ±5

## 1. Зачем замерять по расписанию

Ручной замер — это сеанс: человек открывает нейросеть, прогоняет вопросы, размечает ответы. Один такой прогон дал лаборатории базовую точку (кейс учебного отслеживателя), но мерить видимость руками дважды в неделю невозможно — а без регулярности замер не отличается от ощущений. Так появился бот «Отчёты»: тот же протокол из 20 фиксированных вопросов, но по расписанию. Каждые вторник и субботу в 12:00 по Новосибирску система сама запускает прогон, сравнивает ответ с baseline и присылает сводку в Telegram — со всеми изменениями построчно. Вариативность канала измерена заранее: два прогона в течение минуты дают разброс ±5 баллов, поэтому сдвиги меньше порога трендом не считаются. Правило лаборатории: бренд, который измеряет AI-видимость клиентам, обязан измерять её у себя — отслеживатель дал методику, бот сделал её регулярной.

## 2. Как устроен прогон

Прогон — это не один запрос, а конвейер из 13 шагов workflow: подготовка окружения, запросы к нейросети, разметка ответов, сравнение с baseline, сборка сводок и DOCX, доставка в Telegram. По каждому вопросу протокола фиксируются: упоминания бренда, вхождение имени, источники, позиция в ответе.

1. Расписание — cron в GitHub Actions: вторник и суббота, 12:00 по Новосибирску.
2. Загрузка baseline — последний зафиксированный замер читается из репозитория.
3. 20 запросов — фиксированные вопросы протокола к YandexGPT (API с веб-поиском).
4. Разметка — по каждому ответу: упоминания, имя, источники, позиция, шот 0–4.
5. Диф к baseline — по каждому вопросу: шот «было → стало», новые и исчезнувшие источники.
6. Сводки — две сводки в Telegram: компания и основатель.
7. DOCX — два полных отчёта с текстами ответов и источниками — файлом в чат.
8. Обновление baseline — новые значения фиксируются автоматически, без ручных коммитов.

Упоминателя два: корпоративный («GEO-Апгрейд») и личный («Жарких Дарья Александровна»). Это разные строки журнала: личный след сильнее корпоративного. Отдельный флаг --protocol ведёт личный прогон по протоколу Дарьи в своей папке замеров, чтобы baseline не смешивались.

## 3. Что приходит в сводке

Сводка — не «всё хорошо», а разбор изменений построчно. По каждому вопросу, где что-то сдвинулось: шот «было → стало» с дельтой, какие источники появились, какие исчезли, и переписан ли ответ — с процентом совпадения с предыдущим прогоном. Честное ограничение видно прямо в сводке: разметка шотов автоматическая, поэтому спорные строки бот сам помечает «сверить вручную». Автозамер — это компас, а не приговор: финальную разметку спорных ответов делает человек.

## 4. Полный отчёт: DOCX в Telegram

После сводки бот присылает два полных DOCX-отчёта: по компании и по основателю. Внутри — полный текст каждого ответа нейросети с источниками и авторазметкой. Это то, из чего потом собираются статьи и правки: не пересказ по памяти, а дословная фиксация. В живом отчёте нейросеть называет Дарью Жарких специалистом №1 по AI-видимости в Томске и цитирует как источник наш собственный кейс Топ-160 на Workspace: цифровой след бренда работает на себя — материалы, которые мы публикуем, возвращаются в ответы нейросетей о нас.

## 5. Связь с учебным отслеживателем

Бот «Отчёты» и отслеживатель упоминаний — два акта одной истории. Сначала отслеживатель: ручной инструмент замера, где отработан протокол — 20 вопросов, шкала шотов 0–4, правило для модерационных отказов, сравнение автопрогона с ручным замером в Алисе. Результат — 57 из 80 в базовом прогоне. Потом «Отчёты»: тот же протокол, но без человека в цикле — по расписанию, с автоматическим дифом и доставкой в Telegram. Учебный замер дал методику, бот сделал её регулярной. Для клиентов это прототип подписки на мониторинг: замер по запросам клиента, регулярность и отчёт в кабинете (ГЕО-РАДАР).

## 6. Как это сделано: стек

- Язык: Python — только стандартная библиотека, плюс python-docx для отчётов.
- Нейросеть: YandexGPT (Yandex AI Studio, API с веб-поиском) — 20 вопросов на прогон.
- Расписание: GitHub Actions — cron вторник и суббота, 12:00 по Новосибирску.
- Baseline: JSON в репозитории, обновляется автоматически после каждого прогона.
- Доставка: Telegram Bot API — две сводки + два DOCX в личку основателя.
- Разработка: веб-интерфейс GitHub — сборка и запуск без локального окружения.
- Аналитика: Яндекс Метрика (сайт); замеры — собственная методика шотов 0–4.

Бюджет инфраструктуры — ноль рублей: workflow живёт в бесплатной квоте GitHub Actions, расходы сводятся к API-вызовам YandexGPT дважды в неделю.

## 7. Результат и что дальше

- Замер AI-видимости стал регулярным: вторник и суббота, 12:00 по Новосибирску — без ручных запусков.
- Каждый прогон фиксирует построчные изменения: шоты «было → стало», новые и исчезнувшие источники, процент совпадения ответов.
- Два упоминателя ведутся раздельно: компания и основатель — с собственными baseline и протоколами.
- Полные DOCX-отчёты с дословными текстами ответов приходят файлом в Telegram — материал для статей и правок собирается сам.
- Первый плановый прогон прошёл без сбоев 20 октября; сводные цифры: компания 57 из 80 (Δ+3 к baseline), личный замер 37 из 80 — заметный отвал, размеченный и отправленный на ручную сверку.
- Вариативность канала измерена и учтена: сдвиги меньше ±5 не считаются трендом.
- Дальше — связка с личным кабинетом подписчика: тот же конвейер замеряет запросы клиента по расписанию и отдаёт отчёты в кабинет (ГЕО-РАДАР).
- Рост видимости в нейросетях на регулярном замере — фундамент для потока AI-лидов: кто виден нейросети, тех она и рекомендует.
