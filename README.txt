## КЕШ 10 МИН → 30 ДНЕЙ (не в пакете — настройка панели Cloudflare)
GitHub Pages зашивает кеш 10 минут в свои заголовки, изменить это на самом хостинге нельзя. Но DNS уже на Cloudflare — там кеш переопределяется. Шаги (10 минут):
1. dash.cloudflare.com → домен geo-upgrade.ru
2. DNS → Records → запись A (или CNAME) у корня → Edit → включить «Proxied» (оранжевое облако) → Save. То же для www, если есть отдельная запись.
3. SSL/TLS → Overview → режим «Full».
4. Caching → Cache Rules → Create rule:
   - Имя: static-30d
   - When: URI Path — ends with — .woff2, .css, .js, .webp, .png, .jpg, .jpeg, .svg, .ico (все значения в одно поле списком)
   - Then: Cache eligibility → Eligible for cache; Edge TTL → Respect origin; Browser Cache TTL → Override origin → 1 month
5. Проверка через минуту: сайт открывается по https; curl -I любого woff2 → Cache-Control: max-age=31536000 (или cf-заголовки появились).
ОТКАТ в любой момент: выключить Proxied обратно (серое облако) — сайт вернётся как был за минуту.
Почему 30 дней, а не год: у нас часто-хотфиксы; год без версионирования = пользователи застрянут на старых CSS.
