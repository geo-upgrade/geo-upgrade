# GEO-Апгрейд — пакет №13: хотфикс B6.1 — мобильное меню + полоса основных страниц (10.10)

64 страницы + sitemap (все, кроме главной → 2026-10-10). Главная (index.html) — по-прежнему не тронута.

## Что сломалось в №12 (диагноз)
Мой CSS из №12 добавлялся в конец ПЕРВОГО <style>-блока страницы, а на 45 из 64 страниц этот блок стоит В HEAD ДО подключения tailwind.min.css. По правилам каскада (равная специфичность, порядок подключения) Tailwind побеждал: его .flex перекрывал display:none панели → на таких страницах меню выглядело «всегда открытым», ссылки невидимы (opacity:0 до открытия), панель занимала полстраницы — это и виделось на geo-словаре. На 19 страницах, где <style> идёт после tailwind-ссылки, меню работало как надо. Часть страниц могла отдаваться из CDN-кэша — «где-то нет меню».

## Что исправлено (B6.1)
1. **CSS вынесен в отдельный <style>, вставляемый строго перед </head>** — после всех стилей и tailwind-ссылки, побеждает каскад на каждой странице независимо от порядка существующих блоков.
2. **display:none → display:none!important** для панели и **display:flex!important** только при .jnav-open — двухширотная защита от любых перекрытий.
3. **JS**: header ищется через btn.closest('header') — устойчиво к страницам с двумя <header>.
4. **Полоса основных страниц под хедером (мобайл)** — ВСЕГДА видна: Главная · Услуги · Блог · Кейсы · Топ-160 · Контакты — горизонтальный скролл-ряд чипов с подсветкой текущей страницы (JS по pathname). На Навигаторе — бежевая. Скрывается на десктопе.
5. **noscript-фолбэк**: без JS панель меню видна статично (не заперт контент).
6. **top-160-tomsk.html**: в live-версии не было B6 (файл не долетел при заливке №12) — в №13 включена полная сборка: кнопка + панель + полоса.
7. Старый CSS/JS из №12 полностью удалены со всех страниц (маркер-поиск), двойных кнопок нет.
