# GEO-Апгрейд — пакет №26 (фолбэк мобильного меню + no-JS контент, 09.10)

## Проблема
В Яндекс Браузере на телефоне сайт выглядит «по-старинному»: кнопка меню (бургер) застревает между
двумя строками ссылок, часть контента может казаться пустой. Причина: в этом режиме браузера
не выполняется JavaScript (обычно включён Турбо/экономия трафика) — и срабатывает запасной
(noscript) вариант страницы. Фолбэк был недоработан: бургер оставался видимым между строками,
а карточки (.card/.btn) с классом no-js не «проявлялись» — на 57 страницах класс no-js вообще
не проставлен на <html>.

## Что сделано (65 страниц + sitemap)
1. Носcript-фолбэк мобильного меню переделан на всех 65 страницах:
   - бургер (.jnav-btn) скрывается — он не нужен, когда меню показано статично;
   - меню (.jnav-nav) показывается аккуратной переносимой строкой ссылок-чипов;
   - подпись «МЕНЮ» панели в статичном режиме отключена.
2. На 64 страницах, где <html lang="ru"> без класса, добавлен class="no-js"
   (на geo-upgrade.ru.html класс был пустым — заменён на no-js). Вместе с существующим
   CSS-правилом .no-js .card{opacity:1} это делает контент видимым без JS.
3. Скрипт-съёмщик класса no-js (document.documentElement.classList.remove('no-js'))
   добавлен на 64 страницы, где его не было (после скрипта Яндекс.Метрики — как на главной).
   С JS всё работает как раньше: класс снимается, reveal-анимации работают.
4. sitemap.xml — без изменений: lastmod всех страниц уже 2026-10-10.

## Как проверить фолбэк руками (Chrome)
DevTools → Ctrl+Shift+P → «Disable JavaScript» → перезагрузить мобильного вида страницу:
бургер скрыт, меню — строка ссылок, контент виден.
