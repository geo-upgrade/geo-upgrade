# Пакет «Design Clean» r3 — 17.11.2026

Единая фирменная система для geo-upgrade.ru (94 страницы). Отличия от r2:

1. Кнопки скруглены: на сайте класс .rounded-md стоял на ~490 кнопках, но CSS-правила для него не существовало — кнопки были прямоугольными. Теперь: .rounded-md = 10px, .rounded-lg = 14px, а все кнопки (.btn, .btn-pay, .dgx-buy, .btn-neon, .btn-gold, кнопки городов) — пилюли (999px). Кнопка-бургер навбара — 12px.
2. Кнопки оплаты (.btn-pay) — золотые пилюли с градиентом #F5CD66→#E8B84B, внутренним бликом, тёплым свечением и подъёмом при наведении.
3. Карточки — радиус 14px, при наведении неоновая рамка + лазерная кромка.
4. Интерактивы (квизы, светофоры, чек-листы) не перекрашены: их чипы-варианты уже пилюли (999px), а кнопки внутри оставлены с их формой (8-10px) — как было.
5. Навигаторские страницы (geo_navigator, prompt-map, prompt-compass, navigator-reviews, expedition-lite, expedition-full) — БЕЗ изменений, своя тема сохранена.
6. Плашки категорий на сайте — разноцветные, как было.

## Как заливать
1. Распаковать архив. 2. Загрузить все файлы в корень сайта поверх старых (имена не менять).
3. Проверить на живом сайте; при кэше CDN — ?nocache.

## Проверки при сборке
- JSON-LD валиден на всех страницах (битых 0).
- Пилюли: инжект-блок style#geo-design-system-v2 содержит правила скруглений.
- Платёжные кнопки: класс btn-pay на всех ссылках Точки.
