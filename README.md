# Пакет «Design Clean» r4 — 17.11.2026 (идемпотентный к r3)

Отличия от r3 (правка: «кнопки потехнологичнее»):

1. Кнопки — тех-стиль: прямые почти-углы (4px), светлая верхняя кромка, лёгкий вертикальный градиент — «кнопка приборной панели». Бегущий блик с кнопок убран (лазер остался под шапкой и на карточках при наведении).
2. Кнопки оплаты (.btn-pay, .dgx-buy, .btn-gold) — золотой металлический градиент #F7D271→#E8B84B→#D9A62F с фаской и радиусом 4px.
3. Карточки — 10px (строже). .rounded-md = 8px, .rounded-lg = 10px.
4. Hover: подъём 1px + яркость.
5. Пакет можно заливать ПОВЕРХ r3 целиком: старый блок стилей geo-design-system-v2 в каждой странице заменяется на v2.3, вставки секций не дублируются.
6. Навигаторские страницы — без изменений; плашки категорий — разноцветные.
